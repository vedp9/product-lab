# Product Lab

Product Lab is a curated catalog of smaller, user-facing products, learning builds, experiments, and prototypes. Each project remains in its own repository or deployment so it can evolve independently.

## Portfolio boundaries

These umbrella repositories have distinct jobs:

- **[AI-Product-Studio](https://github.com/vedp9/AI-Product-Studio)** focuses on AI engineering: agentic workflows, RAG, LLM applications, evaluation, safety, and reliability.
- **[Data Systems Lab](https://github.com/vedp9/data-systems-lab)** focuses on the data lifecycle behind analytics and AI: data foundations, analytics reasoning, data quality, pipelines, metrics, retrieval data, and evaluation data.
- **Product Lab** focuses on user-facing products, learning applications, focused experiments, prototypes, and archived work.

Projects are listed here when the primary story is the product experience and the problem it helps a user solve—not the underlying AI or data infrastructure.

## Status legend

- **Product** — an independently usable application.
- **Learning build** — a tool created to support structured learning or practice.
- **Experiment** — a focused exploration of an idea or interaction.
- **Prototype** — an early product concept or implementation.
- **Standalone** — a project owned and presented elsewhere in the portfolio.

Status describes the project’s role in this catalog; it does not imply production readiness.

## Local setup

Each project is maintained independently. For setup, dependencies, environment variables, and run instructions, open the README in the linked repository. Product Lab intentionally has no universal install command.

## Curation principles

- Prioritize a clear user problem over tool novelty.
- Keep each project in one authoritative home.
- Present projects honestly by scope and maturity.
- Prefer focused experiments to unfinished feature lists.
- Link to evidence: source, README, live demo, or documented behavior.
- Revisit project links and statuses periodically.
